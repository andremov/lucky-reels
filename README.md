# Lucky Reels

Slot machine app. You buy a pack of spins with a card, and once the payment clears
you can play the reels.

## Stack

- React + Redux Toolkit + Tailwind, mobile first
- NestJS + Supabase
- Jest
- Vercel for the frontend, Railway for the API
